📖 Deskripsi Singkat

Zenitsu Far Portfolio merupakan sebuah website portfolio pribadi yang dibuat untuk memperkenalkan diri, menampilkan kemampuan, serta menunjukkan beberapa project yang telah dibuat.

Website ini dikembangkan menggunakan HTML, CSS, dan JavaScript. Selain memperhatikan tampilan, website juga dibuat agar dapat memberikan pengalaman yang interaktif dan nyaman digunakan pada berbagai ukuran perangkat.

Website memiliki desain yang responsive sehingga tampilan dapat menyesuaikan ketika dibuka melalui komputer, laptop, tablet, maupun smartphone.

---

🎯 Tujuan Pembuatan

Project ini dibuat dengan beberapa tujuan, yaitu:

- Menerapkan dasar-dasar HTML, CSS, dan JavaScript.
- Membuat sebuah website portfolio pribadi.
- Mempelajari cara membuat website responsive.
- Menerapkan animation dan hover effect pada website.
- Mempelajari penggunaan JavaScript untuk membuat website lebih interaktif.
- Mempelajari proses deployment website agar dapat diakses secara online.
- Menampilkan hasil pembelajaran dalam bentuk project website.

▶️ Cara Menjalankan Project

Untuk menjalankan website secara lokal:

1. Download atau clone project.
2. Buka folder project menggunakan Visual Studio Code.
3. Pastikan seluruh file project berada pada folder yang sesuai.
4. Buka file "index.html".
5. Jalankan menggunakan browser atau extension Live Server.
6. Website akan tampil dan dapat digunakan secara lokal.

Tidak diperlukan instalasi server khusus untuk menjalankan website secara sederhana.

📱 Responsive Design

Website dibuat dengan konsep responsive design agar tampilan dapat menyesuaikan ukuran layar.

Pada layar desktop, beberapa bagian website menggunakan layout yang lebih luas. Sementara itu, pada layar mobile, layout akan menyesuaikan agar konten tetap mudah dibaca dan digunakan.

Responsive design diterapkan menggunakan CSS Media Query.

---

🎨 Interaksi dan Animasi

Website menggunakan beberapa efek visual untuk membuat tampilan lebih menarik dan interaktif.

Contohnya:

- Transisi ketika terjadi perubahan tampilan.

Penggunaan efek tersebut bertujuan agar website tidak hanya menampilkan informasi, tetapi juga memberikan pengalaman penggunaan yang lebih menarik.
